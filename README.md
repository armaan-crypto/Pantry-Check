# Pantry Check

Pantry Check is an app for tracking what's in your pantry and building grocery lists from it. It helps you avoid buying things you already have and cuts down on food waste.

## Features

- Add items to your pantry with quantity, unit, and category
- Search and filter items in your pantry
- Update quantities with a tap, or type in a value
- Swipe to delete an item
- Edit item details at any time
- Support for both American units (lbs, oz) and metric units (grams, liters)
- Data saves automatically, so your pantry stays up to date between sessions
- A clean, simple list view for browsing your items
